## 🌱 Garden Trails Patch Notes v0.1.11
### Removed Yet Another Config dependency:
- The mod do not need YET as a prerequisite anymore
- The configuration is now through a config file.txt in the config folder gardentrails-config
### Configurable plants:
- This config is helping you to customize the biome list of plants, it is completely datadriven
- If you want a plant to not spawn anymore in the the world, just remove all the biomes in the config and leave the field empty like this 'boxwood_bush_biomes='
### Other
- Removed some unused files
